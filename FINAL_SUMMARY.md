## 🚀 БЫСТРЫЙ СТАРТ (3 шага):

### 1️⃣ Убедитесь, что MongoDB запущена
```
- Windows: Services (services.msc) → MongoDB Server
- Или используйте MongoDB Atlas (облако)
```

### 2️⃣ Запустите Backend
```
Откройте: start-backend.bat
Или: cd backend && npm run dev
```

### 3️⃣ Запустите Frontend
```
Откройте: start-frontend.bat (в новом окне)
Или: cd front && npm run dev
Перейдите на: http://localhost:5173
```

## 📡 API ENDPOINTS (11 функций):

```
POST   /api/auth/register       - Создать аккаунт
POST   /api/auth/login          - Войти
GET    /api/auth/me             - Получить текущего пользователя
POST   /api/cart/add            - Добавить товар
GET    /api/cart                - Получить корзину
POST   /api/cart/remove         - Удалить товар
POST   /api/cart/update-qty     - Изменить количество
POST   /api/cart/clear          - Очистить корзину
GET    /api/balance             - Получить баланс
POST   /api/balance/topup       - Пополнить баланс
GET    /api/health              - Проверка статуса
```
