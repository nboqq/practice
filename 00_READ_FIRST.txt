## 📌 САМОЕ ВАЖНОЕ:

### ❌ ЧТО ДЕЛАТЬ НЕ НУЖНО:
- Не менять никакие файлы
- Не закрывать терминалы во время работы
- Не забыть про MongoDB

### ✅ ЧТО ДЕЛАТЬ:

#### Шаг 1: Убедиться, что MongoDB запущена
- Откройте Services (запишите `services.msc` в поиск Windows)
- Найдите "MongoDB Server"
- Если запущена - идите дальше
- Если нет - запустите или используйте MongoDB Atlas

#### Шаг 2: Запустить Backend
1. Откройте PowerShell/CMD
2. Запустите файл: `start-backend.bat`
3. Дождитесь: "Server running on port 5000"

#### Шаг 3: Запустить Frontend (в НОВОМ окне)
1. Откройте второе PowerShell/CMD
2. Запустите файл: `start-frontend.bat`
3. Дождитесь: "Local: http://localhost:5173"

#### Шаг 4: Открыть браузер
Перейдите на: http://localhost:5173

#### Шаг 5: Тестировать функции
1. Нажмите "Регистрация" → заполните форму → "Зарегистрироваться"
2. Добавьте товар в корзину (наведитесь на товар)
3. Нажмите на иконку корзины
4. Нажмите "Пополнить баланс" → выберите сумму → "Пополнить"
5. Нажмите "Выход" (справа в хедере)

## 🆘 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:

### Ошибка: "Cannot connect to MongoDB"
```
Решение: Запустите MongoDB
- Откройте Services (services.msc)
- Найдите "MongoDB Server"
- Нажмите "Start"
```

### Ошибка: CORS error в браузере
```
Решение: 
- Убедитесь, что backend запущен
- Перезагрузите браузер (Ctrl+R)
- Проверьте консоль (F12)
```

### Ошибка: "Cannot add to cart"
```
Решение:
- Сначала зарегистрируйтесь
- Проверьте консоль браузера (F12)
- Посмотрите ошибку и гуглите её
```

### Ошибка: Порт 5000 или 5173 занят
```
Решение:
- Закройте другие приложения использующие эти порты
- Или измените порты в backend/.env и front/vite.config.ts
```
