## 🚀 КАК ЗАПУСТИТЬ

### Требования:
- Node.js v14+
- MongoDB (локально или MongoDB Atlas)

### Шаг 1: Установить MongoDB

**Вариант А (Локально на Windows):**
1. Скачайте MongoDB Community Server:
   https://www.mongodb.com/try/download/community
2. Установите программу
3. MongoDB запустится автоматически как сервис
4. Проверьте, что работает: откройте cmd и напишите `mongod`

**Вариант Б (MongoDB Atlas - облако, рекомендуется):**
1. Перейдите https://www.mongodb.com/cloud/atlas
2. Создайте бесплатный аккаунт
3. Создайте кластер (по умолчанию, выберите зону поближе)
4. Получите connection string
5. Обновите файл `backend/.env`:
   ```
   MONGODB_URI=mongodb+srv://your_username:your_password@your_cluster.mongodb.net/flower-shop
   ```

### Шаг 2: Запустить Backend

Откройте PowerShell/CMD в папке проекта:

```powershell
cd backend
npm run dev
```

Вы должны увидеть:
```
Server running on port 5000
MongoDB connected: localhost
```

### Шаг 3: Запустить Frontend

Откройте ещё один PowerShell/CMD (не закрывая первый):

```powershell
cd front
npm run dev
```

Вы должны увидеть:
```
VITE v... ready in ... ms

➜  Local:   http://localhost:5173/
```

### Шаг 4: Открыть приложение

Откройте браузер и перейдите на: **http://localhost:5173/**

## ✨ ТЕСТИРОВАНИЕ ФУНКЦИОНАЛА

### Тест 1: Регистрация
1. Нажмите кнопку "Регистрация" в правом углу хедера
2. Заполните форму:
   - Имя: Ваше имя
   - Email: test@example.com (может быть любой)
   - Пароль: Любой пароль
3. Нажмите "Зарегистрироваться"
4. ✅ Вы должны увидеть свое имя и баланс (0 ₽) в хедере

### Тест 2: Добавление в корзину
1. Наведитесь на любой товар на главной странице
2. Нажмите кнопку "В корзину"
3. Кнопка должна поменять цвет и текст на "Добавлено"
4. В хедере в иконке корзины должна появиться цифра

### Тест 3: Просмотр корзины
1. Нажмите на иконку корзины в хедере
2. Вы должны увидеть список товаров
3. Попробуйте:
   - Изменить количество (+/-)
   - Удалить товар (кнопка с урной)
   - Видите итоговую сумму внизу

### Тест 4: Пополнение баланса
1. На странице корзины нажмите "Пополнить баланс"
2. Выберите сумму 1000 ₽ (или введите свою)
3. Нажмите кнопку "Пополнить"
4. ✅ Баланс должен увеличиться (в хедере и в окне корзины)

### Тест 5: Выход
1. Нажмите кнопку "Выход" в хедере (справа)
2. Ваше имя и баланс должны исчезнуть
3. Кнопка должна измениться на "Регистрация"
4. При попытке открыть корзину - должна быть надпись "Пожалуйста, войдите"

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **MongoDB должна быть запущена!** Иначе backend не запустится.

2. **Два терминала** - один для backend, один для frontend. Закрывать нельзя.

3. **Порты**:
   - Backend: 5000
   - Frontend: 5173
   - MongoDB: 27017

4. **Если ошибка "Cannot connect to MongoDB"**:
   - Проверьте, что MongoDB запущена
   - Проверьте MONGODB_URI в backend/.env

5. **Если CORS ошибка**:
   - Убедитесь, что backend запущен на http://localhost:5000
   - Убедитесь, что frontend на http://localhost:5173

6. **Если "Cannot add to cart"**:
   - Сначала зарегистрируйтесь и войдите
   - Проверьте, что backend запущен
