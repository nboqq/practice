## 👋 ПРИВЕТ!

Я завершил реализацию всей логики для твоего проекта Flower Shop!

## 📌 ЧТО БЫЛО СДЕЛАНО:

### ✅ Backend (полностью готов)
- **Node.js + Express сервер** на порту 5000
- **MongoDB база данных** для хранения данных
- **JWT аутентификация** для безопасности
- **API Endpoints** для всех операций:
  - Регистрация и вход (/api/auth)
  - Управление корзиной (/api/cart)
  - Пополнение баланса (/api/balance)

### ✅ Frontend (интегрирован с backend)
- **Регистрация/вход** - модальное окно с формой
- **Отображение баланса** в хедере и в корзине
- **Добавление товаров в корзину** при наводке
- **Просмотр корзины** с полным функционалом
- **Пополнение баланса** - выбор суммы или ввод своей
- **Управление аккаунтом** - вход/выход

## 🚀 КАК ЗАПУСТИТЬ (за 2 минуты):

### Способ 1: С помощью BAT файлов (Windows)

1. **Откройте `start-backend.bat`** (запустится backend)
2. **Откройте `start-frontend.bat`** в новом окне (запустится frontend)
3. **Откройте браузер** на http://localhost:5173

### Способ 2: Вручную

Откройте два терминала:

**Терминал 1 (Backend):**
```powershell
cd backend
npm run dev
```

**Терминал 2 (Frontend):**
```powershell
cd front
npm run dev
```

## ⚠️ ПЕРЕД ЗАПУСКОМ:

### 1. MongoDB должна быть установлена!

**Вариант A: Локально на Windows**
- Скачайте: https://www.mongodb.com/try/download/community
- Установите (MongoDB будет запускаться автоматически)
- Проверьте в Services, что запущена

**Вариант B: MongoDB Atlas (облако - рекомендуется)**
- Перейдите: https://www.mongodb.com/cloud/atlas
- Создайте бесплатный аккаунт
- Создайте кластер (выберите зону поближе)
- Получите connection string
- Обновите файл `backend/.env`:
  ```
  MONGODB_URI=mongodb+srv://user:password@cluster.mongodb.net/flower-shop
  ```

## 📱 КАК ЭТО РАБОТАЕТ:

### 1️⃣ Пользователь нажимает "Регистрация"
```
Нажимает → Заполняет форму → Отправляет на backend → 
Backend проверяет email, хеширует пароль, сохраняет → 
Возвращает токен → Frontend сохраняет в localStorage → 
Пользователь залогинен ✅
```

### 2️⃣ Пользователь добавляет товар в корзину
```
Наводит мышь → Видит кнопку "В корзину" → Нажимает → 
Frontend отправляет на backend с токеном → 
Backend сохраняет товар в корзину пользователя → 
Корзина обновляется в UI ✅
```

### 3️⃣ Пользователь открывает корзину
```
Нажимает иконку корзины → Frontend проверяет токен →
Если есть токен, показывает корзину →
Если нет - показывает "Пожалуйста, войдите" ✅
```

### 4️⃣ Пользователь пополняет баланс
```
Нажимает "Пополнить баланс" → Выбирает сумму →
Отправляет на backend → Backend добавляет сумму →
Баланс обновляется везде в приложении ✅
```

## 🚨 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:

1. **Проверьте, что MongoDB запущена**
   - Откройте Services (Windows)
   - Найдите "MongoDB Server"
   - Должна быть статус "Running"

2. **Проверьте консоль браузера** (F12)
   - Ищите красные ошибки
   - Проверьте Network вкладку

3. **Проверьте терминалы backend и frontend**
   - Должны быть сообщения об успешном запуске
   - Проверьте порты 5000 и 5173

4. **Перезагрузите страницу** (Ctrl+R)
