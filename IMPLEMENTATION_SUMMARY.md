### 📡 API Endpoints:

**Authentication:**
- `POST /api/auth/register` - Создать новый аккаунт
- `POST /api/auth/login` - Вход в аккаунт
- `GET /api/auth/me` - Получить информацию о текущем пользователе

**Cart Management:**
- `POST /api/cart/add` - Добавить товар в корзину
- `GET /api/cart` - Получить всю корзину пользователя
- `POST /api/cart/remove` - Удалить товар из корзины
- `POST /api/cart/update-qty` - Изменить количество товара
- `POST /api/cart/clear` - Очистить всю корзину

**Balance:**
- `GET /api/balance` - Получить баланс пользователя
- `POST /api/balance/topup` - Пополнить баланс на указанную сумму

### 🎯 Функциональность:

#### 1. Регистрация и Вход ✅
- Нажимаешь "Регистрация" в хедере
- Заполняешь форму (имя, email, пароль)
- Система отправляет данные на backend
- Backend проверяет, что email уникальный
- Backend хеширует пароль и сохраняет в БД
- Возвращается JWT токен
- Токен сохраняется в localStorage
- Ты автоматически логишься и видишь свое имя и баланс в хедере

#### 2. Добавление товара в корзину ✅
- Наводишь на товар на странице
- Видишь кнопку "В корзину"
- Нажимаешь кнопку
- Товар добавляется в твою корзину на backend'е
- Если товар уже в корзине, увеличивается количество
- Кнопка меняется на "Добавлено"
- Отображается счетчик товаров в иконке корзины

#### 3. Просмотр корзины ✅
- Нажимаешь на иконку корзины в хедере
- Видишь список всех товаров с фотографиями, названиями и ценами
- Можешь изменять количество товаров (+ и -)
- Можешь удалять товары (иконка урны)
- Видишь итоговую сумму
- Видишь твой текущий баланс

#### 4. Пополнение баланса ✅
- На странице корзины видишь кнопку "Пополнить баланс"
- Нажимаешь её
- Появляется модальное окно
- Выбираешь одну из предложенных сумм или вводишь свою
- Нажимаешь "Пополнить"
- Баланс мгновенно пополняется
- Баланс обновляется везде в приложении

#### 5. Выход из аккаунта ✅
- Нажимаешь кнопку "Выход" в хедере
- Токен удаляется из localStorage
- Ты разлогиниваешься
- Кнопка меняется на "Регистрация"
- При попытке доступа к корзине видишь сообщение "Пожалуйста, войдите"

## 🚀 Как запустить

### Шаг 1: Установить MongoDB
**Вариант A: Локально**
- Скачайте MongoDB Community Server с https://www.mongodb.com/try/download/community
- Установите и запустите
- Проверьте, что MongoDB запущен на `localhost:27017`

**Вариант B: В облаке (MongoDB Atlas)**
- Создайте аккаунт на https://www.mongodb.com/cloud/atlas
- Создайте бесплатный кластер
- Получите connection string
- Обновите файл `.env` в backend папке

### Шаг 2: Запустить Backend
```bash
cd backend
npm install    # уже сделано
npm run dev
```
Backend запустится на `http://localhost:5000`

### Шаг 3: Запустить Frontend
В отдельном терминале:
```bash
cd front
npm install    # уже должны быть установлены зависимости
npm run dev
```
Frontend откроется на `http://localhost:5173`

### Шаг 4: Тестировать функционал
1. Откройте браузер на `http://localhost:5173`
2. Нажмите "Регистрация" и создайте аккаунт
3. Добавьте товары в корзину
4. Откройте корзину
5. Пополните баланс
6. Нажмите выход

## ⚠️ Важные замечания

1. **JWT Secret**: В файле `.env` установлен простой secret для разработки. В production нужно изменить на сложный!

2. **CORS**: Backend разрешает запросы только с `localhost:5173` и `localhost:3000`. Обновите это для production.

3. **Безопасность**: Пароли хешируются bcryptjs перед сохранением в БД.

4. **Корзина**: Корзина хранится на backend'е (в документе пользователя), а не в localStorage. Это означает, что корзина сохраняется между сессиями.

5. **LocalStorage**: Токен и данные пользователя хранятся в localStorage для удобства. При выходе они удаляются.

## 🐛 Возможные проблемы

**Проблема**: Cannot connect to MongoDB
**Решение**: Убедитесь, что MongoDB запущен и MONGODB_URI правильный

**Проблема**: CORS error
**Решение**: Убедитесь, что backend запущен на порту 5000, frontend на 5173

**Проблема**: "Cannot add to cart" без ошибки
**Решение**: Проверьте, что вы залогинены (смотрите на имя в хедере)

**Проблема**: Данные теряются после перезагрузки
**Решение**: Данные должны сохраняться в localStorage. Проверьте консоль браузера на ошибки.
